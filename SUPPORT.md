# Support

## Where to go

| I want to…                | Go here                                                                 |
| ------------------------- | ----------------------------------------------------------------------- |
| Report a reproducible bug | [Open a bug report](../../issues/new?template=bug_report.yml)           |
| Request a feature         | [Open a feature request](../../issues/new?template=feature_request.yml) |
| Report a security issue   | Follow [SECURITY.md](SECURITY.md) — never open a public issue           |
| Ask how something works   | [Start a discussion](../../discussions) or read [docs/](docs/)          |
| Contribute code           | Read [CONTRIBUTING.md](CONTRIBUTING.md)                                 |

## Before opening an issue

1. Search existing issues — band pairing and metric-availability reports are common duplicates.
2. Note your platform: iOS TestFlight build, Android app, or browser preview. Web Bluetooth
   behaviour differs sharply between them, and Home Screen PWAs cannot pair the band.
3. For band problems, attach the diagnostic bundle: **Debug tab → Copy debug bundle**
   (admin accounts only). Redact anything you consider personal before pasting.

## Response expectations

This is a small team. Bugs affecting band connectivity or data integrity are triaged first;
everything else is best-effort.
